# Per-address dead ends

One row per address. `recipe_select.py` injects only the row matching the function being worked, so
this file can grow without costing every other session a single byte. Format:

    <addr>\t<what was already tried against the real gate, and failed>

Add a row when a session spends real budget ruling something out. Keep it to what was TRIED and what
it COST; the rule that generalises belongs in core.md instead.
