# Reference sources: Nintendo DS decompilations, each checked by hand before being listed here.
#
# Only a DS decompilation is evidence about DS code, and only DECOMPILED source counts -- a `.s`
# file wrapped in arm_func_start/arm_func_end is a splitter dump, that project's un-decompiled
# leftover, and sdkident drops it at index time regardless of which repository it sits in.
#
# Dragon Quest IX is excluded on purpose. There is one DQIX decompilation and five forks of it,
# ours among them; matching against ourselves would confirm what we already have and prove nothing.
# An independent DQIX project, if one ever appears, would be fair game.
#
# FIRST FIELD IS THE DIRECTORY NAME, SECOND IS THE CLONE URL. The URLs are recorded because they
# were not, and the clones were lost: re-deriving thirteen of them cost a round of web searches.
# Restore the whole set with:
#
#   cd $SP/refs && awk '!/^#/ && NF {print $1, $2}' VERIFIED.txt |
#     while read -r d u; do [ -d "$d" ] || git clone --depth 1 --single-branch "$u" "$d"; done
#   python $SP/sdkident.py index
#
# A repository still has to be a DS decomp to be useful; this file only records that a human
# checked, because the structural test alone rejected genuine projects that vendor the SDK unusually.
