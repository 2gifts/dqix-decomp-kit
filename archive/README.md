# Archive

Finished experiments. They stay because `INVENTORY.md`, `OPEN_RESIDUES.md` and `worker_src/core.md`
cite them as the evidence for a finding. Nothing runs them and nothing maintains them.

- `02061c04/` — the `main:02061c04` campaign (10204 bytes, a 134-case dispatch, now matched):
  per-case grid generators, sweeps and disproofs. They were written to run from `pad/` against
  `c04work/c04.cpp`; copy one back into `pad/` to rerun it.
- `probes/` — minimal compiler-behaviour experiments behind rules in `worker_src/core.md`. Compile
  one with `python pad/probe_cc.py archive/probes/<file>.cpp`.
